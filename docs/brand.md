# Brand

## The story
You're a coder at night, hunched over an old computer like a shrimp. You're stuck on *what should I build?*, so you get a few capsules from the vending machine down the hall. Inside each one is a curled-up shrimp that opens like a fortune cookie and hands you a note: a starting thought. You stick the notes on your board and start writing. Your thoughts start **floppy** (loose, unformed). By the end of the board they're solid enough to build.

## Name and tagline
- **Floppy Thoughts**: floppy shrimp, and loose, unfinished thoughts.
- Tagline: *ideas worth hacking on*.

## Cast
| Element | Role |
|---|---|
| Vending machine | Where random starting notes come from: one row per category, in a drawer beside the board |
| Capsules and shrimp notes | A capsule drops, the shrimp inside cracks open like a fortune cookie, and the note is the slip inside, colour-coded by category |
| The retro computer (device frame) | Where you stick the notes and think |
| Terminal / IDE | How you work: `~/idea` files, `/commands`, Tab completion |
| `// nudges` | Comments someone left in your code: take them or leave them |
| The shrimp | You, the coder, hunched and deep in thought, and the messenger in every capsule. A desk buddy, never a timer |
| Hearts | Favourites you pick yourself. On a shared board you see who picked them, never a score |

## Vocabulary
| Say | Not |
|---|---|
| note(s), shrimp note(s) | spark(s), disk(s) |
| nudge | hint, suggestion |
| idea, thought | node, card |
| board | map, canvas |
| favourite (shown as a heart) | like, star |

## Colour (deep sea)
| Token | Hex | Use |
|---|---|---|
| page | `#17110e` | background |
| surface | `#221914` | panels, cards |
| text | `#f6e3cc` | body text |
| muted | `#bfa086` | secondary text |
| coral | `#ff7a52` | actions (one primary per screen) |
| amber | `#f2b544` | highlights |
| sea | `#7fb7c9` | secondary accent |

**Category colours** are used only for categories, everywhere: words `#ff7a52` · objects `#f2b544` · problems `#7fb7c9` · curiosities `#c69ae0` · nature `#9fd46a` · surprise `#efe7dc`.

All text meets WCAG AA contrast.

## Type
- **Headings:** Bricolage Grotesque (`--font-heading`, easy to swap).
- **Reading:** Atkinson Hyperlegible (`--font-body`), designed for legibility.
- **Monospace:** only for "computer" things: board, terminal, `~/labels`, keys.

## Shapes
Pixel bevels and retro hardware. No pill buttons, no glossy gradients. Illustrations are cosy and pixel-art; the current machine and frame are placeholders for the final art.

## Voice
Short, warm, a little nerdy. Never pushy, never salesy, never rushed.
- *"Start typing your first thoughts, or get a note from the vending machine."*
- *"// what would a dog make of this?"*
- *"No favourites on this board yet. Select anything and press F to keep it here."*

## Don'ts
- No scores, ratings, timers or limits. On your own, favourites aren't counted. On a shared board each box shows who favourited it and how many, so a team can see what it likes; it's never a leaderboard or a score.
- No stars (use hearts).
- No generic hackathon look (black and teal, all caps, pill buttons).
